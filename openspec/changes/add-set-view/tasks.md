# Tasks

## 1. Basics

- [ ] 1.1 Local render: replay a stretch of the log through an offline engine and splice it into the recording at one-deck seams on a beat (short crossfade); an unedited stretch spliced back is not heard
- [ ] 1.2 Change a transition: length in bars and curve (the Automix styles), Listen with a few bars either side, back to as played; undo
- [ ] 1.3 Swap a track: pick a replacement from the library, beatmatched on the same bar for the same stretch, both transitions made again in their recorded style and length
- [ ] 1.4 Save edited mix with transition and swap edits, tracklist and chapters following them

## 2. Advanced editing

- [ ] 2.1 Move transitions with beat and phrase snapping
- [ ] 2.2 Transition editor: both tracks on one beatgrid, drawn curves, as-played ghost, A/B
- [ ] 2.3 Loops: drag to change length or repeat count, or remove
- [ ] 2.4 Hard moves: Keep from recording (copied audio, the default) or Bypass

## 3. Capture and whole-set render

- [ ] 3.1 Control changes stamped with their audio frame through a ring from the audio thread
- [ ] 3.2 Plugin parameter changes and instrument / Groove Box notes in the log
- [ ] 3.3 Setting to record Mic and Aux to their own files beside the recording
- [ ] 3.4 Deck place every audio block while a deck is scratched, backspun or braked
- [ ] 3.5 Whole-set render through the engine; null test against an unedited recording
