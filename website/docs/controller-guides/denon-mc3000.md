## Getting started

The MC3000 is a four-deck controller from 2012 that works with the
computer's own sound card or one you add. Plug it in with its USB cable
and openDJ picks this mapping by itself.

The mapping is Mixxx's, written for the MC3000 when it came out. Nobody
has tried it in openDJ on a real MC3000 yet, so tell us how it goes.

- **Decks:** **DECK CHG.** switches each side between its two decks;
  **LOAD A/C** and **LOAD B/D** load the deck that's showing.
- **The mixer:** **LEVEL**, **HI**, **MID**, **LOW** and the channel
  faders set openDJ's mixer. **CF MODE** changes the crossfader.
- **Hot cues:** **CUE 1** to **CUE 8**.
- **Loops:** **LOOP IN**, **LOOP OUT** and **AUTO LOOP**, with **+** and
  **−** for the loop size.
- **Effects section:** on the left, the four **EFX** knobs set the flanger
  and the microphone level and the four buttons play beat loops (or the
  four samplers, when the section is in sample mode). On the right, the
  knobs set the headphone mix, headphone level, main balance and main
  level.
- **SAMPLE** and **EFX** kill the mids on decks A and B.

The **FILTER** knobs aren't mapped.

## When you try it

- Switch each side to decks 3 and 4 and back.
- Try the hot cues and loops.
- Try the left **EFX** buttons in both modes.
