## Getting started

The MC6000MK2 is a four-channel controller and mixer. Plug it in with its
USB cable and openDJ picks this mapping by itself; it's also the sound
card. Set each channel's input selector to **PC** to play an openDJ deck
through it.

The mapping is Mixxx's. Nobody has tried it in openDJ on a real
MC6000MK2 yet, so tell us how it goes.

- **Decks:** **DECK 1/3** and **DECK 2/4** switch each side between its
  two decks.
- **The mixer:** **LEVEL**, **HI**, **MID**, **LOW**, **FILTER** and the
  channel faders set openDJ's mixer. **CUE** sends a channel to the
  headphones, and the front panel's crossfader assign switches and
  **X FADER CONTOUR** set the crossfader.
- **Effects:** both effect units work: **ON** turns an effect on and the
  three knobs set it. **CH ASSIGN** sends a channel to a unit.
- **Loops:** **IN**, **OUT** and **AUTO LOOP**, with **+** and **−** to
  change the loop size.
- **Browsing:** turn **TRACK SELECT** to move through the list and press
  **LOAD ◄** or **LOAD ►** to load a deck.

The microphone, echo and main and booth levels work in the hardware
itself.

## When you try it

- Switch each side to decks 3 and 4 and back.
- Turn both **FILTER** knobs and check each moves its own channel.
- Try both effect units on one channel.
