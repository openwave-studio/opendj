## Getting started

Plug the Mixon 8 Pro into the computer with its USB cable; openDJ picks
this mapping by itself. Play through the Mixon 8 Pro's own sound card: pick
it in **Settings › Audio**.

This is openDJ's own mapping, built from the list of controls djay Pro's
built-in mapping uses. Nobody has tried it in openDJ yet, so tell us how it
goes.

- **Four decks:** each side's deck buttons switch between decks 1 and 3 or
  2 and 4.
- **Pad modes:** the four buttons above the pads, and with **SHIFT** four
  more: hot cue, bounce loop, slicer, neural mix; pitch play, saved loop,
  sampler and instant FX. Each deck keeps its own mode.
  - **NEURAL MIX**: the top row mutes a stem, the bottom row plays one
    alone.
  - **Saved loop** pads do nothing yet.
- **FX sections:** each works on the deck you last used on its side. The
  three knobs set effects 1 to 3, the fourth their amount. The stem
  routing buttons aren't mapped yet.

## When you try it

- Check it shows up in **Settings › Controllers**.
- Play, cue and sync all four decks, and scratch with the jogs.
- Try each pad mode and both FX sections on decks 1 and 3.
